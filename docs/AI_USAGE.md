### 1. AI Tools Used
* **Google Gemini** (Collaborative debugging, architectural reflection, and documentation structuring).

### 2. Tasks Where AI Was Used

* Implementing the `urgent_only` boolean query parameter in FastAPI report endpoints.
* Troubleshooting Swagger UI OAuth2 Bearer authentication flows and case-sensitive credential inputs.
* Structuring and formatting documentation files (`INDIVIDUAL_REFLECTION.md`, `AI_USAGE.md`).

### 3. Example Prompts Used

* *"Why am I getting a 401 Unauthorized error in Swagger UI when testing the login token?"*
* *"How can I safely remove tracked SQLite `.db` files from Git without deleting them locally?"*

### 4. Code or Suggestions Accepted
* Using `Query(False)` for the optional `urgent_only` flag in FastAPI routes.
* Using `git rm --cached` to stop tracking local database files while keeping `.gitignore` rules clean.
* Structured templates for project reflection and reporting.

### 5. Code or Suggestions Rejected
* Suggestions to replace SQLModel dependencies with raw SQLAlchemy query builders (rejected to preserve original project architecture).
* Hardcoding secret keys directly inside `config.py` files.

### 6. Errors Produced by AI

### 7. How Generated Code Was Verified
* Executed the automated test suite (`pytest -v`) to confirm zero regressions.
* Interactively tested API responses and status codes (`200 OK`, `401 Unauthorized`) in Swagger UI.
* Inspected database queries generated by SQLModel to verify `urgent_only` filtering behavior.

### 8. What Was Learned From Using AI

* Learned to evaluate AI suggestions critically, applying code only after step-by-step independent verification.
